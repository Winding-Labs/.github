# Winding Labs

We're a small software studio. This is what we make.

## For families

- **Tumbly: Kids Engineering Games.** Kids to Engineers: four engineering games for kids 3 to 12. The app's code is private; the app is at [tumbly.ai](https://tumbly.ai/).

## For people who build software

- **Zest.** AI coding analytics for engineering teams: which coding agents, models and skills each engineer uses, what they cost, and which sessions end in merged pull requests. The plugins are public: [zest-cli](https://github.com/Winding-Labs/zest-cli), [zest-claude](https://github.com/Winding-Labs/zest-claude), [zest-codex](https://github.com/Winding-Labs/zest-codex), [zest-opencode](https://github.com/Winding-Labs/zest-opencode), [zest-hermes](https://github.com/Winding-Labs/zest-hermes), [zest-grok](https://github.com/Winding-Labs/zest-grok) and [zest-freebuff](https://github.com/Winding-Labs/zest-freebuff).
- **Glow.** [glow-agent](https://github.com/Winding-Labs/glow-agent) sends what your coding agents do to your Glow channels, and lets you message them back from Glow. MIT license.
- **AI code review benchmark.** [ai-code-review-benchmark](https://github.com/Winding-Labs/ai-code-review-benchmark) is open data on how AI code review apps and LLM reviewers score on real public pull requests: F1, latency and cost per review. CC BY 4.0.
